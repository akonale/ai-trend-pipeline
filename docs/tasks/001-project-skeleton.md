# 001: Project skeleton

Status: pr-open

## Goal

Set up an empty, installable Python 3.12 project managed by uv. It should have Pydantic and the Temporal SDK as dependencies, Ruff and Pyright (strict) for linting and type checks, and pytest for tests, all run through a justfile. The project does nothing yet. It only has to pass `just lint` and `just test`.

## Acceptance criteria

- [x] `uv sync` on a fresh clone creates `.venv` with Python 3.12 and installs runtime deps (`pydantic>=2`, `temporalio`) and dev deps (`ruff`, `pyright`, `pytest`) from a committed `uv.lock`.
- [x] Package `ai_trend_pipeline` lives under `src/` (src layout), includes a `py.typed` marker, and can be imported as `import ai_trend_pipeline`.
- [x] `just lint` runs `ruff check .`, `ruff format --check .` and `pyright`, and exits 0. Pyright runs in `strict` mode over `src` and `tests`.
- [x] `just test` runs `pytest` and exits 0, with at least one test collected (pytest exits 5 when it collects no tests, which would fail).
- [ ] `just fmt` runs `ruff format .` and `ruff check --fix .`. Running `just` with no arguments lists the recipes.
- [x] All tool config (ruff, pyright, pytest) is in `pyproject.toml`. There are no separate `ruff.toml`, `pyrightconfig.json` or `pytest.ini` files.

## Files to touch

- `pyproject.toml` (new): project metadata, `requires-python = ">=3.12,<3.13"`, deps, `[dependency-groups] dev`, build backend (hatchling or uv_build), `[tool.ruff]` (line-length 100, target py312, rule sets at least `E,F,I,UP,B`), `[tool.pyright]` (`typeCheckingMode = "strict"`, `pythonVersion = "3.12"`, `include = ["src", "tests"]`, venv settings pointing at `.venv`), `[tool.pytest.ini_options]` (`testpaths = ["tests"]`)
- `.python-version` (new): `3.12`
- `uv.lock` (new, generated by `uv lock`)
- `justfile` (new): `default`, `lint`, `fmt`, `test` recipes, each running tools through `uv run`
- `src/ai_trend_pipeline/__init__.py` (new): module docstring and `__version__` only
- `src/ai_trend_pipeline/py.typed` (new, empty)
- `tests/__init__.py` (new, empty) if needed for pyright/pytest discovery
- `tests/test_smoke.py` (new)

## Tests to write

- `test_package_imports`: `import ai_trend_pipeline` works and `__version__` is a non-empty `str`.
- `test_core_deps_importable`: `pydantic` and `temporalio` import, and `pydantic.VERSION` starts with `"2"`.

## Out of scope

- CLAUDE.md (task 002).
- docker-compose, Postgres, Temporal dev server, `just dev`, and any workflow or activity code (task 003).
- GitHub Actions or other CI config (task 004).
- Pre-commit hooks, coverage tooling, mypy, extra dependencies (httpx, Vega, etc.).
- Changes to `infra/`, `.claude/`, `.gitignore` or `docs/mvp-plan.md`. The existing `.gitignore` already covers `.venv`, caches and build output.
